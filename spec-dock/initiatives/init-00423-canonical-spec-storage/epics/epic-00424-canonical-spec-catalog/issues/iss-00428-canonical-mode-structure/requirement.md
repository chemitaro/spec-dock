# iss-00428 Add Canonical Mode And GitHub Structure Snapshot — 要件定義

詳細: [Requirement Guide](../../../../../../docs/authoring/requirement.md)

## 目的
canonical モードの土台になる、モードの判定と、GitHub の構造の読み書きができる。構造は一括で取得して使い回し、GitHub に負荷をかけない。利用者から見える変化はまだない。

- 材料：Epic の `plan.md` の「I-1 Add Canonical Mode And GitHub Structure Snapshot」の節（価値、作るもの、受け入れ、注意）と、Epic の `design.md` の担当の章（1、2（構造のスナップショットを含む）、6章の I-1 の行）。Issue をまたぐ契約は、`plan.md` の「Issue をまたぐ契約」の表に従う。
- 依存（`plan.md` の I-番号）：なし。Planning Level：strict。
- 実装担当は、着手のときに、この要件定義書と `design.md`、`plan.md` を、上の材料から具体化する（`plan.md` の「実装担当への共通の指示」）。
