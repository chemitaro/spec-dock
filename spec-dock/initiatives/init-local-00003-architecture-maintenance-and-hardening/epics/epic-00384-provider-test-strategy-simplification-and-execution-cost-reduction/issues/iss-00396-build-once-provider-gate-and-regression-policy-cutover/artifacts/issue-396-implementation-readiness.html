1. Issueの目的とEpic内の位置

Epic #384は、Issue #392のprovider lifecycleとIssue #395の先行変更を経て、Issue #396でfinal provider gateへ切り替える計画です。#396はbuild-once packaging、same-candidate downstream roles、Linux canonical、sdist smoke、macOS delta、actual-byte evidence、qualification evidence、required-context cutover、旧policy retirementを一つのIssue acceptance単位として所有します。

現在の最重要停止条件: ownerは#395の実装自体が誤りと報告しています。具体的defectと修正後のtipは未確認です。#395 ownerが#395のscope内で修正・受入し、GitHub readbackでcorrected SHA/treeを確定するまでB1/B2対象は未確定で、Issue #396のProduct実装は開始できません。

仕様作成、formal start、implementation dispatch、Product実装、human merge、post-merge B3、Epic main mergeは別々の状態です。
