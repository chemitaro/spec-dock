# 旧migration・共通writer admissionの退役

## 対象と方針

採用済み [D-12](../design.md#d-12) / [CLI契約](cli-contract.md) に従う。読取基準は `747e7da61baa88209cd0ff3d107625a6a656b37d`。旧五source filesの1505行・52 top-level symbolsと、旧二test filesの920行・22 test関数を全文確認した。

旧処理はschema1のScope/activeをschema3へ変換し、全登録worktreeの宣言、common Gitのcontrol/registry、永久branch binding/local ID予約をまとめて更新した。UUID付きmigration journalへbefore/after bytesとphaseを保存し、resume/rollbackで再実行した。

現在の対象は既存schema3である。一つの明示workspaceだけを外部へ実体保全し、別のscratch directoryへの復元も照合してからwriter_protocol宣言を一file公開する。Scope metadata・ID/linkage/未知field、旧active、他worktree、Git内の旧情報を変換・再登録・修復しない。registry/journal/operation_id・自動resume/rollbackを復活させない。

候補外source/test AST importはTYPE_CHECKING/from-import子moduleを含め0。退役後の参照は通常wheelの不在assert、fresh-processの旧admission非load assert、既知旧資産のpath/hashだけ。alias/fallback/pytest skip/収集除外を増やさない。

## 五十二symbolsへの対応

同一rowのsymbolsは同じ判断で扱う。

| 旧module | symbols | 後継／退役理由 |
|---|---|---|
| application/migrate_workspace_vnext | inspect_workspace_migration、load_workspace_migration_map、MigrationChange、PreparedMigrationPlan、prepare_workspace_migration、_encode、_snapshot、plan_migration_changes | schema1/全WTの変換計画とmappingを廃止。direct_migrationの現current snapshot・planned出力・入力再照合へ統合 |
| application/migrate_workspace_vnext | _desired_worktrees、_finish_migration、_continue_migration、apply_workspace_migration、_file_digest、resume_workspace_migration、rollback_workspace_migration | 登録/epoch/journal続行・rollbackを廃止。外部実体保全後のcurrent一file公開とpartial effectsを維持 |
| infra/migration_store | MigrationScope、MigrationWorktree、MigrationInventory、MigrationMap、MappingFileIdentity、read_mapping_snapshot、mapping_file_identity、branch_tip、read_migration_map | registration/mapping/backend override/permanent branch bindingを廃止。Git現物identity、現Scope構造検査、局所input照合へ統合 |
| infra/migration_store | _digest、_read_json、_metadata_paths、_classify_scope、_active_focus、_inspect_worktree、inspect_migration_inventory | 全WTの全Scope変換分類/旧active focus移植を廃止。workspace_structure/scope_treeとread-only legacy_readerを使う |
| infra/migration_journal | MigrationFile、MigrationRecord、_digest、_directory、_managed_file、_validate、_encode、_decode、read_migration_record、write_migration_record、_write_record_file、pending_migrations | Git common dirのdurable migration journal全体を廃止。新規書込・resume token・snapshot続行なし。旧recordのheader観測はlegacy_readerで行い実行可能とは認定しない |
| infra/migration_executor | _digest、_guard_path、snapshot_migration_file、_publish、apply_migration_file、preflight_rollback_file、rollback_migration_file | journalのbefore/afterをrootへ反映するexecutorを廃止。現行direct_json/migration_backup/tree_backupの局所公開・実保全を維持 |
| cli/admission | AdmissionError、admit_writer | 全writerのcontrol/epoch/engine/登録/pending/maintenance gateを廃止。project_contextと現domain writer_admissionのschema/feature/protocol検査を維持 |

`domain/writer_admission.py` は現行project_context、scope_tree/scope_metadata、start_snapshot、direct_migrationが使用するため保持する。`migration_backup.py` はcurrent migration/static updateの保全に必須で保持する。`legacy_reader.py` とcurrent migration writerも変更しない。registry/writer_lock/control等の残る旧helpersは別unitでcallerを確認する。
