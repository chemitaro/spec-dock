# 決定: 固定ディレクトリ再配置へEpicを再構成する

- 状態: accepted（2026-09-19の明示ユーザー指示）
- 基点: 851020134f460373adf00453798c49f163b08f8d

## 背景

ユーザーはデータと配布コードの領域が分離されていることを踏まえ、ディレクトリの削除とコピーだけへ戻し、複雑化したEpic要件・設計・コード・旧テストを再構成するよう明示した。

## 決定

親Requirement R1〜R10を採用する。6固定ディレクトリを丸ごと交換し、利用者データへ触れない。更新中断は外部installerを再実行する。個別ファイル保持、provider状態機械、認証marker、旧版exact移行、性能認証、履歴管理を廃止する。旧artifactと#392/#395のR/D/Pは歴史資料であり、新契約と競合する保証は今回の実装に適用しない。

## 明示する影響

管理対象内のローカル変更も消える。更新中のコマンド実行は禁止。途中失敗の原子的復旧は保証しない。既存consumerのCIは変更せず、新規CI自動seedは廃止する。利用者データの保持と、残る一般機能の正しさはテストする。

## 検証

旧性能認証を通すことではなく、新しい配置契約をテストし、通常回帰・lint・package smoke・独立レビューを通す。人間のマージ境界は保持する。
