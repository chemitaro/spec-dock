4. 確定した所有境界

      
providerの固定mutation setは4 roots、2 slots、small record、fresh init時だけの2 seed作成です。seedは作成後consumer-ownedとなり、update / reinstall / uninstallでは変更しません。user data、unknown paths、shared parentを管理対象へ広げません。small recordはuninstall後もtooling-absent-preserved-dataとして残り、never-installed absentと区別します。

7. Issue #392の実装milestone

      
次はIssue分割ではなく、同じ実装ユニットの内部順序です。

      
    
        
  1. M1 Successor contract freeze: ownership、record、marker、legacy recognizer、CLI result、lane ownershipをtest-firstで固定します。
    2. 
        
  2. M2 Minimal lifecycle core: no-follow binding、stage、ready / incomplete / durable tooling-absent record、root / slot replacement、fault seamsを実装します。
    3. 
        
  3. M3 Combined public cutover: init / update / uninstall / reinstallとpublic docsをfinal servicesへ接続し、reinstallがfresh-init-only seedsを再作成しないことを固定します。
    4. 
        
  4. M4 Legacy / downgrade proof: exact 0.2.3 migration、unsupported block、old-package mutation-zeroをbuilt artifactで証明します。mutation-zeroはPython filesystem eventsとnative renameat2 / renameatx_npを覆うstartup composite tripwire event 0が主証拠です。native positive controlsのcall前捕捉とtree digest不変も必須です。
    5. 
        
  5. M5 Old product / test removal: successor proof後だけper-file engine、journal、purge、historical testsを削除します。
    6. 
        
  6. M6 Failure / portfolio consolidation: active 26 nodesをterminal化し、ledgerとpolicy skipをなくします。
    7. 
        
  7. M7 Build-once gate: one build、Linux canonical、macOS delta、metrics、duplicate detectorを実装します。
    8. 
        
  8. M8 Old CI removal: new gate確認後にparity重複、Full Regression、sharder、timing machineryを削除します。
    9. 
        
  9. M9 Final acceptance: 5 runs、fault pack、rolling 20、required context、人間mergeを完了します。
    10.

9. 受け入れ条件

      
    
        
  • provider mutation authorityが4 roots、2 slots、fixed record、fresh-init-onlyの2 seed作成に限定され、seedへのupdate / reinstall / uninstall authorityがありません。
    • 
        
  • user history、.workbench、unknown non-target、unrelated skills、consumer seedsがbyte-identicalです。
    • 
        
  • fresh、exact 0.2.3 migration、update、tooling uninstall、reinstallがbuilt wheelでGREENです。
    • 
        
  • uninstall後のdurable recordがnever-installed absentと識別され、reinstallがconsumer seedsを再作成しません。
    • 
        
  • active legacy recovery、unsupported / foreign / symlink stateはmutation 0でblockされます。
    • 
        
  • old 0.2.3 packageのmutating commandsがcomposite tripwire event 0かつtree digest不変で、native renameat2 / renameatx_np positive controlsがcall前に捕捉されます。
    • 
        
  • --remove-specsは全modeでmutation 0、exit 2です。
    • 
        
  • seeded root / slot fault後にsame-candidate rerunで収束し、cross-intent rerunをblockします。
    • 
        
  • unexpected failures、approved failures、policy skips、duplicate nodesがすべて0です。
    • 
        
  • single-process 5 runsが各600秒以内、CPU/wall 1.1以下です。
    • 
        
  • artifact build invocation 1、seeded fault detection 100%、rolling 20 flakes / retries 0です。
    • 
        
  • old Full Regression、ledger、timing weights、sharder、policy hooksが削除されています。
    • 
        
  • canonical provider contextとhuman review gateを維持しています。
    • 
        
  • human merge後のtreeがverified PR treeと同一です。
    • 
      

      
一つでも未達なら#392をcloseしません。調査Issueや検証Issueを追加せず、同じ実装ユニットを修正します。
