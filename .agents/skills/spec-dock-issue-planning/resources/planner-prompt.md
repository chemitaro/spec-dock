scope, current and target architecture, ChatGPT First workflow, provider-owned direct Oracle versus
reference-only operator `chatgpt-use`, Candidate/Review/Human/apply lifecycle, exact-branch failure,
current status, remaining roadmap, provider/projection, failure modes, and a first-day checklist.

responsibility-boundary, planning-sequence, and implementation-roadmap roles.
