# spec-deps/current

このディレクトリは、`spec-dock` 自体の「依存関係（deps）可視化/判定」を刷新するための、仕様書駆動開発用の作業スペースです。

## 使い方（最小）
- `requirement.md` / `design.md` / `plan.md` / `report.md` を起点に作成・更新します。
- `adrs/` 配下に ADR を追加します（雛形: `adrs/_template.md`）。
- 補足資料・ログは `artifacts/` 配下へ追加します（雛形: `artifacts/_template.md`）。

## テンプレートについて
このディレクトリの初期ファイル群は、`src/spec_dock/assets/spec_dock/templates/issue/`（issueテンプレート）をコピーして作成しています。
